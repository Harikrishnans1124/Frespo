How Frespo Works

Frespo converts Spotify playlists into YouTube playlists automatically. Simply provide a Spotify playlist URL and Frespo handles the migration process.

Conversion Process

Step 1

Paste a Spotify playlist URL into the input box.

Step 2

Frespo fetches all songs from Spotify using the Spotify API.

Step 3

Songs are matched against YouTube search results.

Step 4

A new YouTube playlist is created automatically.

Step 5

All matched songs are added to the playlist and ready to use.

Technology Stack

Backend

FastAPI, PostgreSQL, Python

APIs

Spotify API and YouTube Data API v3
